        📲 Pasang sebagai aplikasi
        
            
        Android (Chrome/Edge): menu ⋮ → Install app / Tambahkan ke layar utama. iPhone/iPad (Safari): Bagikan → Tambahkan ke Layar Utama.
        
            
        Aplikasi dari layar utama punya penyimpanan sendiri: masukkan kode pairing sekali lagi di sana. Halaman tidak di-cache untuk offline (token sesi tidak boleh tersimpan di cache browser).

        Pilih project

        Cari di percakapan ini

        Kirim / baris baru

        Tips
        
            
          
              
        • Mode tim: AI mendelegasikan ke PM, BA, developer, QA, dan lainnya. Kantor lebih hidup, tapi token lebih banyak.
          • 
              
        •  Riwayat sesi melanjutkan percakapan lama, termasuk yang dimulai di terminal. Menu ⋯ menyalin perintah untuk melanjutkan sesi web di terminal.
          • 
              
        • Sesi yang kamu jalankan di terminal (CLI) ikut tampil live di sini.
          • 
              
        • Tandai project yang sering dipakai dengan ★ di daftar project supaya selalu di atas.
          • 
              
        •  Pengaturan notifikasi (per jenis kejadian, jam tenang, hanya project favorit, volume): buka palet Ctrl P (di HP: tombol 🔎 di bawah) → Pengaturan notifikasi. Di laptop juga lewat klik kanan 🔔 atau ⚙ Pengaturan.
          • 
              
        • Klik kartu anggota tim di bawah kantor untuk mengganti nama mereka.
          • 
              
        •  Buka di HP: scan QR-nya, lalu pilih Add to Home Screen agar Adhitron tampil seperti aplikasi. Lewat WiFi HP hanya bisa melihat; lewat Tailscale bisa mengirim perintah.

                                    Aktifkan akses saat PC terkunci
                                    
        
                                    
          
                                    Sandi akun, bukan PIN. Yang diminta adalah sandi akun Windows/Microsoft (untuk akun Microsoft: sandi akun Microsoft-mu, sama seperti saat login di situs Microsoft) — PIN Windows Hello yang kamu pakai sehari-hari tidak bisa dipakai di sini. Sebaiknya nyalakan BitLocker dan pakai akun Windows khusus untuk Adhitron. Windows meminta izin Administrator sekali; batalkan di jendela itu bila berubah pikiran.

                                        Agent
                                        
          
          
                                        
          
                                        Kosongkan prompt untuk menghapusnya. Agent bawaan OpenCode tidak perlu ditambahkan di sini. Mode, langkah, warna, sembunyikan, dan nonaktif mengikuti config OpenCode V2.
                                        
          
                                        References
                                        
          
                                        
          
                                        Folder lokal (mis. ~/pustaka) atau repository Git yang boleh dibaca agent. Alias tanpa spasi, /, backtick, atau koma; branch hanya untuk repository. Kosongkan alias untuk membuang baris.
                                        
          
                                        Instructions
                                        
          
                                        
          
                                        File, glob, atau URL instruksi yang selalu dibaca OpenCode — mis. AGENTS.md, ~/aturan/*.md, https://contoh.test/aturan.md. Maksimal 100 entri.
                                        
          
                                        Sumber skill
                                        
          
                                        
          
                                        Folder lokal (./team-skills, ~/shared/opencode-skills) atau katalog HTTP berisi index.json. Skill bawaan OpenCode dan folder .opencode/skills tetap dibaca tanpa entri di sini.
                                        
          
          
                                        Provider tool pencarian OpenCode. Bawaan membiarkan OpenCode memilih; Nonaktif menghapus tool pencarian. Kunci (API key) provider diatur dari 👤 Akun → provider web search.
                                        
          
                                        
          
                                        Command = file .opencode/commands (project) atau ~/.config/opencode/commands (semua project). Memakai $ARGUMENTS, $1, dan !`cmd`; OpenCode memuat ulang otomatis.
                                        
          
                                        
            🛡️ Policies (hard-deny)
            
                                        Statement biner allow/deny yang hanya mengetatkan izin (tidak pernah bertanya). Urutan dipertahankan; statement terakhir yang cocok menang. Contoh: tool.use + shell:git push * + deny.

Field experimental.* bisa berubah di rilis OpenCode berikutnya.
