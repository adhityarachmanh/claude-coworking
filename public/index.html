        ❓ Panduan Adhit Office
        
        
        
          
        
            
        Mulai dalam 4 langkah
        
            
          
              
        1. Pilih project: klik nama project di kiri atas, atau tekan Ctrl K.
          2. 
              
        2. Ketik permintaan di chat, atau klik salah satu ide di layar sambutan. Claude Code bekerja langsung di folder project itu.
          3. 
              
        3. Setujui izin: saat tim mau mengedit file atau menjalankan perintah, kartu izin muncul di chat.
          4. 
              
        4. Cek hasilnya di tab Perubahan (diff per file), lalu commit.
          5. 
            
        
          
        
          
        
            
        Shortcut keyboard
        
            
        
              
        Ctrl KGanti project
        
              
        Ctrl PPalet perintah: semua aksi, file (@), project (#), perintah (>) — Ctrl Shift P langsung ke perintah
        
              
        EnterKirim pesan
        
              
        Shift EnterBaris baru
        
              
        Alt Enter📋 Tambah ke antrian (juga tombol 📋 di samping Kirim, atau /antrian): prompt dijalankan satu per satu otomatis saat tim tidak sibuk
        
              
        ↑ ↓Panggil lagi prompt sebelumnya (di kotak pesan)
        
              
        /Slash command & skill, misalnya /compact atau /context
        
              
        @Sebut file di project
        
              
        /t⚡ Template prompt (review, test, perbaiki error, commit…), juga tombol ⚡ di kotak pesan. Bagian {…} langsung terpilih; Tab ke bagian berikutnya
        
              
        Ctrl VTempel gambar atau screenshot
        
              
        !Jalankan perintah shell langsung di folder project, misalnya !git status. Output-nya ikut terkirim ke Claude bersama pesan berikutnya.
        
              
        Shift TabGanti mode izin (Tanya dulu → Auto-edit → Rencana → Auto)
        
              
        EscHentikan giliran yang berjalan (pesan yang antre ikut dibatalkan), atau tutup dialog
        
              
        Esc EscKosongkan kotak pesan; kalau sudah kosong, buka Rewind: kembalikan kode dan/atau percakapan ke sebelum salah satu pesanmu
        
              
        Ctrl RCari di riwayat prompt
        
              
        Ctrl BPindahkan perintah/agent yang sedang jalan ke latar belakang
        
              
        /clear /model /effort /resumeSesi baru · ganti model · ganti effort · riwayat sesi
        
              
        /rewind /mcp /tasks /memoryRewind · server MCP (status, login) · tugas latar · buka CLAUDE.md
        
              
        /usage /context /compact /rename …Command Claude Code lain jalan seperti di terminal; ketik / untuk daftar lengkapnya
        
              
        ?Buka panduan ini
        
            
        
          
        
          
        
            
        Mode izin
        
            
        
              
        🛡️ Tanya duluSetiap edit file dan perintah menunggu izinmu. Paling aman.
        
              
        ✏️ Auto-edit fileEdit file langsung jalan, perintah terminal tetap minta izin.
        
              
        ⚡ AutoAksi yang dinilai aman langsung jalan, yang berisiko diblokir.
        
              
        📋 Rencana duluClaude menyusun rencana dulu, dan baru dikerjakan setelah kamu setujui.
        
              
        🚫 Jangan tanyaTidak ada kartu izin: yang belum diizinkan lewat aturan langsung ditolak. Untuk kerja tanpa ditunggui.
        
            
        
          
        
          
        
            
        Tips
        
            
          
              
        • Mode tim: Claude mendelegasikan ke PM, BA, developer, QA, dan lainnya. Kantor lebih hidup, tapi token lebih banyak.
          • 
              
        • 🕘 Riwayat sesi melanjutkan percakapan lama, termasuk yang dimulai di terminal. Menu ⋯ menyalin perintah untuk melanjutkan sesi web di terminal.
          • 
              
        • Sesi yang kamu jalankan di terminal (CLI) ikut tampil live di sini.
          • 
              
        • Tandai project yang sering dipakai dengan ★ di daftar project supaya selalu di atas.
          • 
              
        • Klik kartu anggota tim di bawah kantor untuk mengganti nama mereka.
          • 
              
        • 📱 Buka di HP: scan QR-nya, lalu pilih Add to Home Screen agar Adhit Office tampil seperti aplikasi. Lewat WiFi HP hanya bisa melihat; lewat Tailscale bisa mengirim perintah.
          • 
            
        
          
        
        
        
      
        
    
        

    
    
        
      
        
        
        👥 Nama anggota tim
        
        
        Nama tampil di kantor, chat, aktivitas, dan laporan. Kosongkan untuk kembali ke nama bawaan. Berlaku di laptop dan HP.
        
        
        
          
        
          
        
            
            
            
          
        
        
        
      
        
    
        

    
    
        
      
        
        
        👥 Kelola tim 
        
        
        Pilih role bawaan yang punya meja di kantor. Role nonaktif tidak dipakai: pekerjaannya dialihkan ke role aktif terdekat. Berlaku untuk proses Claude Code berikutnya (sesi yang diam dimulai ulang otomatis) dan di semua perangkat.
        
        
        Lewat WiFi hanya bisa melihat. Pakai laptop atau Tailscale untuk mengubah tim.
        
        
        
          
          
          
          
          
          
            
            
            
          
          
        
          
      
          
    
          

    
    
          
      
          
        
          🕘 Riwayat sesi 
          
        
          Lanjutkan percakapan Claude Code sebelumnya di project ini, baik dari terminal (CLI) maupun dari web. Isi percakapannya dimuat ke chat dan Claude ingat konteksnya.
          
        
          
          
          
        
          
        
        
          
      
          
    
          

    
    
          
      
          
        
          ⏪ Rewind
          
        
          Pilih pesanmu. Kode dan/atau percakapan dikembalikan ke keadaan sebelum pesan itu dikirim, seperti Esc Esc di Claude Code.

              🛡️ Aturan izin  
              
        
              Aturan yang disimpan "Izinkan selalu" (seperti /permissions di Claude Code). allow jalan tanpa bertanya · ask selalu tanya · deny selalu ditolak (deny menang). Berlaku untuk proses Claude Code berikutnya: sesi web yang diam dimulai ulang otomatis; sesi di terminal setelah dibuka ulang.
              
        
              Hanya bisa diubah dari laptop (aturan ini menentukan apa yang boleh dijalankan Claude tanpa bertanya).

                ⚡ Template prompt
                
        
                
          
                
            
            
          
                
          
                
          
                
          
                
            
            
            
            
            
          
                
          
                ↑↓ pilih · Enter sisipkan · Esc tutup. Template masuk ke kotak pesan (tidak langsung dikirim); bagian {…} langsung terpilih untuk diisi, Tab ke bagian berikutnya.

                📋 Antrian 
                
        
                
          
                
          
        
                
        
                  
        
                  
          
          
          
        
                  
        
                  
          
          
          
        
                  
        
        
                  
          
                  
            
            tanpa batas
            
          
                  
          
                  
          
                  
            
            
            
                  
              
              
            
                  
          
                  
          
                  
          
                  Dicek setelah tiap item selesai; giliran yang berjalan tidak dipotong. Biaya hanya estimasi (harga list).
                  
          
                  
        
                  
        
                  Satu item dikirim setiap kali giliran sebelumnya selesai (tidak ada izin yang menunggu). Antrian berhenti sendiri bila item gagal/dihentikan, kuota habis, atau batas antrian tercapai, dan tetap dijeda setelah server di-restart sampai kamu melanjutkan. Seret atau ↑↓ untuk mengubah urutan.

            ⏳ Peringatan kuota
            
            
                  
              
               %
              
               %
            
                  
            
                  
            
                  Per jendela kuota (sesi 5 jam, mingguan): toast dan notifikasi (bila 🔔 aktif) sekali per ambang tiap periode reset, plus penanda berwarna di atas. Dibaca dari sesi yang berjalan, tanpa request tambahan. Disimpan di browser ini.
                  
          
                  
          
                  
          
                  
            💾 Cadangkan riwayat
            
                  Untuk pindah laptop atau install ulang: Export di sini, lalu Import di laptop baru dan lanjutkan percakapan lama (Riwayat sesi di app maupun claude --resume). Ikut: semua sesi Claude Code di semua project (termasuk subagent, memori, checkpoint, rencana, riwayat prompt) plus data kantor ini (folder, favorit, nama tim, laporan token). Login tidak ikut: login ulang dengan claude di laptop baru.
                  
            
                  Hanya dari laptop.
