        ❓ Panduan Adhit Office

        Mulai dalam 4 langkah

        1. Pilih project: klik nama project di kiri atas, atau tekan Ctrl K.
        2. Ketik permintaan di chat, atau klik salah satu ide di layar sambutan. Claude Code bekerja langsung di folder project itu.
        3. Setujui izin: saat tim mau mengedit file atau menjalankan perintah, kartu izin muncul di chat.
        4. Cek hasilnya di tab Perubahan (diff per file), lalu commit.

        Mode izin

        🛡️ Tanya duluSetiap edit file dan perintah menunggu izinmu. Paling aman.
        ✏️ Auto-edit fileEdit file langsung jalan, perintah terminal tetap minta izin.
        ⚡ AutoAksi yang dinilai aman langsung jalan, yang berisiko diblokir.
        📋 Rencana duluClaude menyusun rencana dulu, dan baru dikerjakan setelah kamu setujui.
        🚫 Jangan tanyaTidak ada kartu izin: yang belum diizinkan lewat aturan langsung ditolak. Untuk kerja tanpa ditunggui.

        Tips

        • Mode tim: Claude mendelegasikan ke PM, BA, developer, QA, dan lainnya. Kantor lebih hidup, tapi token lebih banyak.
        • 🕘 Riwayat sesi melanjutkan percakapan lama, termasuk yang dimulai di terminal. Menu ⋯ menyalin perintah untuk melanjutkan sesi web di terminal.
        • Sesi yang kamu jalankan di terminal (CLI) ikut tampil live di sini.
        • Tandai project yang sering dipakai dengan ★ di daftar project supaya selalu di atas.
        • Klik kartu anggota tim di bawah kantor untuk mengganti nama mereka.
        • 📱 Buka di HP: scan QR-nya, lalu pilih Add to Home Screen agar Adhit Office tampil seperti aplikasi. Lewat WiFi HP hanya bisa melihat; lewat Tailscale bisa mengirim perintah.
        👥 Nama anggota tim

        Nama tampil di kantor, chat, aktivitas, dan laporan. Kosongkan untuk kembali ke nama bawaan. Berlaku di laptop dan HP.

        🕘 Riwayat sesi

        Lanjutkan percakapan Claude Code sebelumnya di project ini, baik dari terminal (CLI) maupun dari web. Isi percakapannya dimuat ke chat dan Claude ingat konteksnya.

        ⏪ Rewind

        Pilih pesanmu. Kode dan/atau percakapan dikembalikan ke keadaan sebelum pesan itu dikirim, seperti Esc Esc di Claude Code.
