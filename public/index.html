        ❓ Panduan Adhitron
        
        
        
        
          
        
            
        📲 Pasang sebagai aplikasi
        
            
        Android (Chrome/Edge): menu ⋮ → Install app / Tambahkan ke layar utama. iPhone/iPad (Safari): Bagikan → Tambahkan ke Layar Utama.
        
            
        Aplikasi dari layar utama punya penyimpanan sendiri: masukkan kode pairing sekali lagi di sana. Halaman tidak di-cache untuk offline (token sesi tidak boleh tersimpan di cache browser).
        
            
          
        
          
        
            
        ⌨️ Shortcut keyboard
        
            
        
              
        Ctrl K
        Pilih project
        
              
        Ctrl P
        Palet perintah (semua aksi); Ctrl Shift P langsung ke perintah
        
              
        Ctrl F
        Cari di percakapan ini
        
              
        Ctrl R
        Cari riwayat prompt (di kotak pesan)
        
              
        Ctrl B
        Lanjutkan perintah/subagent di latar belakang
        
              
        Enter / Shift Enter
        Kirim / baris baru
        
              
        Alt Enter
        Masukkan prompt ke antrian (tidak langsung dikirim)
        
              
        Shift Tab
        Ganti mode Build ⇄ Plan
        
              
        Alt M
        Input suara
        
              
        Esc
        Tutup dialog/menu teratas; tanpa dialog, hentikan giliran
        
              
        Esc Esc
        Rewind percakapan/kode saat tidak ada yang berjalan
        
              
        ?
        Buka Panduan ini (juga dari mana saja, kecuali saat mengetik)

        1. Pilih project: klik nama project di kiri atas, atau tekan Ctrl K.
          2. 
              
        2. Ketik permintaan di chat, atau klik salah satu ide di layar sambutan. Mesin AI bekerja langsung di folder project itu.
          3. 
              
        3. Setujui izin: saat tim mau mengedit file atau menjalankan perintah, kartu izin muncul di chat.
          4. 
              
        4. Cek hasilnya di tab Perubahan (diff per file), lalu commit.
          5. 
            
        
          
        
          
        
            
        Shortcut keyboard
        
            
        
              
        Ctrl KGanti project

        EnterKirim pesan
        
              
        Shift EnterBaris baru

        ↑ ↓Panggil lagi prompt sebelumnya (di kotak pesan)
        
              
        /Slash command & skill, misalnya /compact atau /context

        !Jalankan perintah shell langsung di folder project, misalnya !git status. Output-nya ikut terkirim ke Claude bersama pesan berikutnya.

        Mode
        
            
        
              
        🔨 BuildFile boleh diubah otomatis. Perintah shell dan jaringan tetap minta izin; aturan deny selalu menang.
        
              
        📋 PlanMesin hanya menyusun rencana, tanpa mengubah file. Setujui dengan Lanjut build untuk mulai bekerja.
        
            
        
          
        
          
        
            
        Tips
        
            
          
              
        • Mode tim: mesin mendelegasikan ke PM, BA, developer, QA, dan lainnya. Kantor lebih hidup, tapi token lebih banyak.
          • 
              
        • 🕘 Riwayat sesi melanjutkan percakapan lama, termasuk yang dimulai di terminal. Menu ⋯ menyalin perintah untuk melanjutkan sesi web di terminal.
          • 
              
        • Sesi yang kamu jalankan di terminal (CLI) ikut tampil live di sini.
          • 
              
        • Tandai project yang sering dipakai dengan ★ di daftar project supaya selalu di atas.
          • 
              
        • 🔔 Pengaturan notifikasi (per jenis kejadian, jam tenang, hanya project favorit, volume): buka palet Ctrl P (di HP: tombol 🔎 di bawah) → Pengaturan notifikasi. Di laptop juga lewat klik kanan 🔔 atau ⚙ Pengaturan.
          • 
              
        • Klik kartu anggota tim di bawah kantor untuk mengganti nama mereka.
          • 
              
        • 📱 Buka di HP: scan QR-nya, lalu pilih Add to Home Screen agar Adhitron tampil seperti aplikasi. Lewat WiFi HP hanya bisa melihat; lewat Tailscale bisa mengirim perintah.
