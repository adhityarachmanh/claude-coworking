# "Chat umum" Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Tambahkan satu project bawaan "Chat umum" yang memakai mesin chat yang sama seperti project (Claude Code / OpenCode), tetapi bekerja di folder sandbox milik aplikasi sehingga konteksnya global.

**Architecture:** Entri project bersumber `system` dengan id tetap `chat-umum` dan `path` = `<dataDir>/chat-umum/` didaftarkan di `Hub` dan dipertahankan oleh `refreshProjects()`. Sesi memakai jalur project biasa; rute destruktif (purge/archive/data-project) menolaknya, dan picker menampilkannya paling atas dengan ikon 💬 tanpa tombol hapus/arsip.

**Tech Stack:** Node >= 20, ES modules, `node:test` + `node:assert/strict`, UI statis vanilla JS.

**Spec:** `docs/superpowers/specs/2026-11-22-chat-umum-design.md`

## Global Constraints

- Teks yang tampil ke pengguna **Bahasa Indonesia**; komentar kode **bahasa Inggris**.
- Id tetap entri bawaan: `chat-umum`. Nama tampil: `Chat umum`.
- Sandbox: `<dataDir>/chat-umum/` (ikut `hub.dataDir`), dibuat dengan `mkdirSync(..., { recursive: true })`.
- Nol dependency npm baru.
- Isolasi data test: pembuatan Hub di test memakai `dataDir` sementara (`mkdtempSync`), seperti `test/budget.test.mjs`.
- Commit message Bahasa Indonesia, satu topik per commit.
- Jangan menyentuh/menghapus data project user.

## Review Focus

- **`refreshProjects()` pada saat start dengan `state.json` lama**: entri `chat-umum` belum ada di `projects` — harus dibuat, bukan hanya dipertahankan. Uji: hub baru tanpa entri tetap memunculkannya setelah `ensureSystemProjects()`.
- **Sandbox dihapus user di tengah jalan**: `ensureSystemProjects()` harus membuat ulang foldernya (tanpa error bila sudah ada). Uji: hapus folder, panggil lagi, folder ada.
- **Entri `system` tidak boleh ikut dihitung "project nyata" di health** (dulu `demo`/`virtual` dikecualikan). Uji: `buildHealth` tak menghitungnya.
- **Rute destruktif oleh id langsung** (bukan lewat UI): `purge`, `archive`, dan `data/project` harus menolak id `chat-umum` dengan 409/404. Uji: panggil rute dengan id itu.
- **Urutan picker**: entri `system` selalu di paling atas, apa pun statusnya. Uji: `projectRank` mengembalikan nilai > semua project lain; dan ikon 💬.

```js
// test/chat-umum.test.mjs — entri bawaan "Chat umum": selalu ada, sandbox-nya dibuat, dan tak bisa dipurge.
import assert from 'node:assert/strict';
import { existsSync, mkdtempSync, rmSync } from 'node:fs';
import { tmpdir } from 'node:os';
import path from 'node:path';
import { after, test } from 'node:test';
import { GENERAL_ID, Hub } from '../src/hub.js';

const temps = [];
function tempDir() {
  const dir = mkdtempSync(path.join(tmpdir(), 'office-chatumum-'));
  temps.push(dir);
  return dir;
}
after(() => { for (const dir of temps) rmSync(dir, { recursive: true, force: true, maxRetries: 5, retryDelay: 200 }); });

test('Hub mendaftarkan entri "Chat umum" dengan sandbox-nya', () => {
  const dir = tempDir();
  const hub = new Hub({ dataDir: dir });
  const p = hub.projects.get(GENERAL_ID);
  assert.ok(p, 'entri chat-umum harus ada');
  assert.equal(p.name, 'Chat umum');
  assert.equal(p.system, true);
  assert.equal(p.path, path.join(dir, 'chat-umum'));
  assert.ok(existsSync(p.path), 'folder sandbox harus dibuat');
});

test('ensureSystemProjects membuat ulang sandbox yang dihapus', () => {
  const dir = tempDir();
  const hub = new Hub({ dataDir: dir });
  rmSync(hub.projects.get(GENERAL_ID).path, { recursive: true, force: true });
  hub.ensureSystemProjects();
  assert.ok(existsSync(hub.projects.get(GENERAL_ID).path), 'folder sandbox harus dibuat lagi');
});
```

- [ ] **Step 3: Implement in `src/hub.js`**

Tambah konstanta dekat `DEMO_ID`:

```js
export const GENERAL_ID = 'chat-umum';
```

Tambah metode `ensureSystemProjects()` pada kelas `Hub` (di dekat `upsertProject`), lalu panggil dari konstruktor setelah `this.projects.set(DEMO_ID, …)`:

```js
  /**
   * The built-in "Chat umum" entry: a project with the same engines as any other, but its folder is an app-owned
   * sandbox under dataDir — so a general chat never touches a real project folder. Called at start and on every
   * rescan, so deleting the entry (or its folder) still leaves it present.
   */
  ensureSystemProjects() {
    const dir = path.join(this.dataDir, GENERAL_ID);
    try {
      mkdirSync(dir, { recursive: true });
    } catch {
      // unreadable folder: the session start still reports the real error
    }
    let project = this.projects.get(GENERAL_ID);
    if (!project) {
      project = { id: GENERAL_ID, name: 'Chat umum', path: dir, sources: ['system'], system: true };
      this.projects.set(GENERAL_ID, project);
    }
    // A first-seen entry starts on the app-wide default engine (same rule as upsertProject).
    if (!ENGINES.includes(this.persisted.settings?.[GENERAL_ID]?.engine)) {
      this.persisted.settings ??= {};
      this.persisted.settings[GENERAL_ID] = { ...this.persisted.settings?.[GENERAL_ID], engine: this.defaultEngine() };
    }
    return project;
  }
```

Kode: `this.ensureSystemProjects();` diletakkan tepat setelah `this.projects.set(DEMO_ID, …)` pada akhir konstruktor.
